# 在线播放与下载控制（当前 0.3.3）

0.3.3 在线播放器已改用 Media3 ExoPlayer，保留原有手势和本地播放器；前台增加网络提前缓冲、范围重开和自动重试，复用可用 CDN 节点。具体参数、真实视频/清单验证和真机验证边界见 [本次调查](research/scene-corpus/findings.md)。以下记录 0.3.2 的基础设计，其中“平台 MediaPlayer 直接读取 MediaDataSource”已被替换；下载暂停/取消行为继续适用。

## 0.3.2 基础设计记录

视频详情点“在线播放”，沿用播放器进度拖动、横滑快进/后退、亮度/音量、倍速、长按 2×、缩放及旋转。需登录具有 WE 下载资格的 Steam 账号，由 Steam 授权清单和密钥，不绕过购买与作品可见性。场景/Web/Application 不提供原始视频在线播放。

通过 Android MediaDataSource 的 readAt/getSize，按实际读取位置定位 Steam 块，读取、解密/解压并核对长度、Adler 和块 SHA-1。支持先读尾部索引、跨块、任意位置拖动。项目描述也只在内存读取校验，不创建下载任务、不写视频临时文件，不通过公开 localhost 或暴露 CDN 签名链接播放。

解码块 LRU 缓存上限 32 MB，单次 readAt 最多返回 1 MB。网络压缩块、当前解码块和系统播放器还有额外内存开销，所以 32 MB 不是整个播放器的总内存上限。退出或后台取消此来源的请求并清空缓存，不取消共享 Steam 会话或其他下载；返回前台重新建立来源并恢复本次位置。

在线播放仍消耗流量。原始码率不变，没有服务端转码/自适应清晰度；高码率、尾部索引、网络延迟、授权和编码影响首帧与拖动缓冲。不支持的手机编码不能靠流式解决。全文件 SHA-1 不能在未读全视频时宣称通过，因此对实际读取块逐个验证。

已保存中的活动/排队任务都有暂停/继续与取消下载。暂停中断请求并保留续传文件；取消确认后先停工作，再清理任务、partial、场景各文件暂存和未发布副本，收藏保留。排队任务不用等待前一个完成才停止。晚到的取消不会删除已完成内容；已完成内容通过原管理功能删除。进程中断后重启会继续清理已确认取消的未完成任务。

取消仅针对当前 SteamCdn 持有的 Call，不对共享客户端 cancelAll；解析与哈希循环检查中断，发布前重新确认停止标记。短暂系统/解码收尾用“正在停止”表示。

已保存页删除创作按钮；仅在静态图片“设为壁纸”页出现“制作分层场景”，默认勾选当前图片。效果参数和全屏预览仍在壁纸设置流程内。

验证：612 项核心检查，覆盖随机/尾部/跨块读取、LRU、损坏块校验、正在读取时关闭、独立 CDN 请求取消、活动/排队暂停取消和恢复；15 项正式 VideoDownloadService 主机检查验证保留/清理文件、排队不发起网络、不删除已完成视频及其他任务互不干扰。26 项正式内容/参数、13 项发现到场景解析检查通过。

主机使用合成资源和 Android/会话替身，不等于真实 Steam 视频和手机播放器验收。本轮不操作手机界面。用户自行测试首帧、拖动至尾部、退出重进、活动与排队暂停/续传/取消及空间释放。
