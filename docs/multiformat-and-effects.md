# 格式与壁纸效果

## 从发现到壁纸

在「发现」或「收藏」下载作品，在「已保存」查看进度和解析结果。视频点击后播放；长按内容可收藏、删除或设为壁纸。资源保存在应用私有目录，下载成功后清理转换暂存文件。

## 格式

| 内容 | 处理方式 |
| --- | --- |
| MP4、WebM 等视频 | 使用 Android 媒体解码，支持播放、视频壁纸和选帧静态壁纸 |
| PNG、JPEG、WebP 等图片 | 使用 Android 图片解码，可设置静态或交互壁纸 |
| GIF、动态 WebP | 使用动画解码与壁纸渲染 |
| PKGM、PKGV、MPKG、PKG、ZIP | 解析容器和项目引用，提取视频、图片或适配图层场景 |
| 基础图片图层场景 | 转换为本应用运行格式，保留图层布局与支持的交互 |
| WallpaperMobileScene/1 | 本应用分层格式，可调整图层参数 |

场景适配支持常见图片纹理、图层位置/缩放/旋转/透明度/视差，以及特定双图指针遮罩的触摸 X-ray。SceneScript、自定义着色器、复杂粒子和音频响应等效果需要进一步适配。下载时会根据实际资源给出解析结果。

## 视频壁纸设置

- 水平镜像，运动响应选择关闭、设备倾斜或桌面滚动。
- 播放速度、背景色、亮度、对比度、饱和度与色相。
- 铺满保持原比例，拉伸填充屏幕，自由模式可调整缩放和位置。
- 自动或自定义背景分段。系统省电策略位于右上角「通用设置」。

## 图片与场景设置

支持姿态视差、相对拖动、构图与颜色调整，以及图层深度、透明度和位置参数。支持的 X-ray 图层可配置触摸揭示范围。图片设置页还可制作分层场景。

## 体感与场景设置

体感基于初始握持姿态计算相对倾斜，横竖屏切换时重新居中；屏幕上下、左右方向分别映射，避免竖直握持时的欧拉角耦合。

图片与场景使用统一的卡片设置，分为体感与拖动、桌面翻页、构图与颜色、触摸与叠加，以及资源实际具备的透视与图层参数。启用翻页后，拖动优先交给翻页，触摸透视仍可使用。

场景没有正在变化的图层交互时，缓存合成结果，通过 GPU 移动画面；体感、拖动或触摸透视变化时恢复实时合成。同尺寸纹理更新复用已有存储。

## 桌面滚动与预览

预览与实际壁纸共用渲染器和设置模型。实际桌面默认只跟随系统偏移，不再依据手指速度预测翻页。全屏预览中的翻页控件模拟背景位置。自动分段优先采用启动器报告的页数，否则按素材与屏幕比例计算；手动模式可设置 1～12 页。

铺满模式可从一侧滑到另一侧，覆盖完整可移动区域。拉伸与自由模式 显示完整画面时没有额外裁切区域，放大后可产生横向移动余量。桌面滚动只应用于桌面配置。

首次启用动态壁纸通过系统确认。之后可更新已启用范围的内容，桌面与锁屏分别保存配置。
