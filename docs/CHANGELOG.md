# 版本记录

## 0.5.3

- 桌面滑动兼容恢复默认开启，自动补偿不连续报告偏移的启动器。
- 修正曾收到一次系统偏移后永久禁用手势补偿的问题，系统优先级限定在当前手势。
- 普通横滑即可翻动背景，降低过高的提交门槛；短滑、回拖与取消恢复起点。
- 支持只转发按下和松开事件的启动器，保留只跟随系统的设置。

## 0.5.2

- 体感改用相对姿态和屏幕坐标，修正竖直握持时上下倾斜引起横向偏移。
- 默认跟随系统实际翻页，移除速度预测；手势估算作为通用设置中的可选兼容模式。
- 省电静态移至右上角通用设置，对所有壁纸生效。
- 场景设置统一卡片、分段选项和可视化配色，按资源显示透视与图层参数。
- 场景翻页不再叠加触摸拖动；稳定图层采用合成缓存和 GPU 相机移动，同尺寸纹理复用更新。

## 0.5.1

- 修正切换锁屏等范围时重复连接预览显示区域的问题，范围切换复用当前渲染器。
- 串行释放与重建预览，短暂切后台时暂停并复用；临时显示错误支持重试。
- 视频设置采用统一卡片样式，运动和画面适配改为中文分段按钮。
- 背景色提供命名色块与可视化调色面板，支持实时预览、确认及取消还原。

## 0.5.0

- 回归自有壁纸引擎，整理视频画面、运动响应和颜色设置。
- 优化桌面滑动跟随与动画，增加自动分段和自定义页数。
- 增加系统省电模式静态画面及自动恢复。
- 支持将 Hydrogen 的官方包重新下载为主线运行版本。

## Hydrogen 0.4.2

- 通过官方 Wallpaper Engine Android 导入和设置视频、MPKG。
- 使用每个工坊作品独立的文件名，修正导入覆盖问题。
- 增加官方客户端版本检查和兼容提示。

## 0.3.x

- 手机独立工坊查询、下载与在线播放。
- 下载暂停、继续、取消和已保存管理。
- 视频、图片、动画及基础图层场景适配，增加触摸 X-ray。
- 壁纸预览、图层参数、姿态视差与桌面滚动。

## 0.2.x 及更早版本

- 工坊筛选、分页、预览和收藏。
- Steam 登录恢复和私有目录下载。
- 内置视频播放器及图片、视频壁纸设置。
