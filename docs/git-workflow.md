# 贡献与 Git 工作流

主线 `main` 维护独立 Android 应用与自有壁纸引擎。Hydrogen 是官方客户端接入版，作为独立版本归档。

## 提交改动

1. 从主线创建 `feature/<topic>` 或 `fix/<topic>` 分支。
2. 保持提交聚焦，使用 `feat:`、`fix:`、`docs:`、`test:` 等前缀说明目的。
3. 运行相关检查和 `git diff --check`，说明测试范围。
4. 整合完成后发布版本标签，保留已有标签。

## 发布与隐私

公开仓库从经过脱敏的源码快照开始；本地开发历史单独保留。后续公开版本使用普通提交追加，保留公开仓库已有历史。

提交源码、通用文档和可复现检查。SDK、缓存、签名、账号、下载资源、个人参考图和设备证据由 `.gitignore` 排除。安装包通过 Releases 分发，附带版本说明与 SHA-256 摘要。

## Android 版本

主线和 Hydrogen 均使用 `dev.workshopvideo`。同签名且 versionCode 递增的 APK 可覆盖更新并保留数据；发布时同时更新版本名和 versionCode。

官方 MPKG 与主线场景格式分开处理。资源迁移成功后再替换原文件，失败或取消保留原内容。
